## 💡 Quick Reference

### Implementation Details
- Logs: `remote_clients/{client}/{workflow}_wf_{id}/run_logs/`
- Telemetry: `telemetry/telem_{timestamp}/`
- Workflow IDs: SHA256 hash (wf_{hash[:12]})
- Components: LogsTerminal.vue, AgentStatusBar.vue
- Polling: 5 seconds for telemetry when active

### Message Flow
1. Agent → Agent server (workflow status)
2. Agent server → DNNE server (WebSocket)
3. DNNE server → UI clients (broadcast)
4. UI agentStore updates clientWorkflows Map
5. Components reactively update
